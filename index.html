Click any empty photo box to add your dish image (or drag a file onto it). Once added, scroll to zoom, drag to reposition, or use the + / − / ⟳ buttons. Click any name or description to edit; use A− / A+ to resize the title text, ▭− / ▭+ to resize the white banner behind it, and ◇ to change its shape (blob / brush / ribbon / oval). Prices start empty — click the ··· beside THB and type the number (boxes left empty export with no price); the THB label itself is editable too. Use P− / P+ to resize the price, drag its ≡ grip to move it, and +2 to add a second price for products with two options. Type SET as a price for a SET stamp.
